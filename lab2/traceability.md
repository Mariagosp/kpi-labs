# Матриця трасування вимог

Матриця показує зв'язок **багато-до-багатьох** між функціональними вимогами, сценаріями Gherkin та варіантами використання Wishlist Service (одна вимога може покриватися кількома сценаріями/UC; один сценарій або UC — кількома вимогами).

| Вимога | Сценарії | Варіанти використання | Покриття |
|---|---|---|---|
| REQ-01 — Створення списку | SC-01 | UC-01 | Покрито |
| REQ-02 — Обмеження доступу до приватного списку | SC-02 | UC-02 | Покрито |
| REQ-03 — Перегляд публічного списку | SC-08 | UC-04 | Покрито |
| REQ-04 — Додавання товару | SC-09 | UC-03 | Покрито |
| REQ-05 — Бронювання доступного товару | SC-03 | UC-05, CheckItem (`<<include>>`) | Покрито |
| REQ-06 — Заборона бронювання власного товару | SC-04 | UC-05, CheckItem (`<<include>>`) | Покрито |
| REQ-07 — Скасування бронювання | SC-05 | UC-06 | Покрито |
| REQ-08 — Позначення товару завершеним | SC-06 | UC-07 | Покрито |
| REQ-09 — Скасування бронювання завершеного товару | SC-06 | UC-07, CancelOnComplete (`<<extend>>`) | Покрито |
| REQ-10 — Приховування особи того, хто забронював товар | SC-10 | UC-02 | Покрито |
| REQ-11 — Автентифікація користувача | SC-11 | UC-08 | Покрито частково |
| REQ-12 — Надсилання запрошення | SC-07 | UC-09, CheckPublic (`<<include>>`) | Покрито |

Приклади M:N у матриці:
- **один UC → кілька REQ:** UC-05 покриває REQ-05 і REQ-06; UC-02 — REQ-02 і REQ-10; UC-07 — REQ-08 і REQ-09.
- **один сценарій → кілька REQ:** SC-06 покриває REQ-08 і REQ-09.
- **одна REQ → кілька UC:** REQ-05/REQ-06 — UC-05 + CheckItem; REQ-09 — UC-07 + CancelOnComplete; REQ-12 — UC-09 + CheckPublic.
