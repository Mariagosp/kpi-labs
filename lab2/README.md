# Лабораторна робота №2 — Вимоги та Use Cases

## Мета
Сформулювати вимоги до Wishlist Service, описати сценарії використання та перевірити трасованість між вимогами й артефактами.

## Структура
- `spec.md` — актори, бізнес-правила та Use Cases.
- `user-stories.md` — користувацькі історії.
- `scenarios.feature` — Gherkin-сценарії.
- `traceability.md` — матриця трасованості.
- `use-case-diagram.puml` — діаграма Use Case.
- `audit.md` — аудит вимог і моделі.
- `DEFENSE.md` — звіт для захисту.

## Перевірка
Діаграму можна переглянути за допомогою PlantUML. Трасованість перевіряється за відповідністю ідентифікаторів вимог, сценаріїв і Use Cases.

## Основа
Робота продовжує модель даних Wishlist Service з лабораторної роботи №1.
